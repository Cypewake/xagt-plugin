## 一、先把评分表钉死（不猜，不编）

官方硬门槛只有三条，**全过才进正式评分**：

1. **资格** —— 没碰安全/审计/链上风控红线（我们过）。
2. **API 可验证** —— 被封装的 API 必须真实可调用（不是我们的服务要常驻公网）。
3. **源码评审** —— 有测试、有 README（我们过）。

官方定性口径原话：*"genuinely useful, online-callable, API-backed capability"*。
排名规则：每赛道前 5 拿 X-Points，1st = 500 USDT + 15k。
**目标 = 头奖（第 1 名），不是进前 5。**

关键事实（官方明示）：*"You do not need to build your own MCP Server before submitting."*
→ **重部署公网、赶 GitHub 提交，对排名指针的影响 ≈ 0。** 它们是浪费，先删。

## 二、用五步算法过一遍当前方案

| 步骤 | 动作 | 结论 |
|---|---|---|
| 1 质疑需求 | "我们必须部署/必须赶 GitHub PR 吗？" | 规则没要求。删。 |
| 2 删除 | 删掉「重部署 v2.1」「抠部署细节」 | 省下的时间扔进杠杆区。 |
| 3 简化（关键） | 把「工具策展」从「矛」降级为「桌」 | Speakeasy/Gram 都做 scope filtering，它不是独特差异点。 |
| 4 加速 | 选一个真实有用的 API 当样板 + 重写评委视角文档 | 5 天内只做这两件高杠杆事。 |
| 5 自动化 | 暂缓 | 非瓶颈。 |

**核心修正**：我们之前把「工具策展（Curation）」当成了夺冠的矛。错。
策展是**桌子**——没有它 Agent 用不好，但对手（Speakeasy、Gram）也都做了。
真正的**矛**是：**完整跑通官方四段式，并且在最常被跳过的两段（Verify、Monetize）做真、做透。**

---

## 三、矛：完整四段式 + Verify/Monetize 真实闭环

官方主题四个词：**Build → Verify → MCPize → Monetize**。
多数参赛作品停在 MCPize（生成工具就走）。少数做 Verify（且往往"任意响应都算通过"）。
**几乎没人做 Monetize。**

我们的不对称优势（已落地、可复核）：

| 阶段 | 我们做了什么（真实） | 对手普遍状态 |
|---|---|---|
| Build | OpenAPI spec → 注册表持久化 | 同 |
| Verify | **真实 2xx 才算通过**，401/403/404/4xx 严格区分 | 多数"可达即过"，指标恒真 |
| MCPize | 生成可调用工具 + **SSRF 逐跳校验**（`request_with_validated_redirects`） | 多数直连，存在重定向绕过风险 |
| Monetize | **真实用量计量**（usage.json 原子写）+ 计价档出账 + 市场清单 | 几乎空白 |

→ 评委看到自己喊的口号被一个作品**逐字、真实**地实现，记忆点就立住了。
这不是"比谁生成得多"，是"比谁收得尾"。

## 四、样板必须用「真实有用的 API」，不是 Petstore 自嗨

Petstore 只能证明"能生成"，证明不了"genuinely useful"。
我们用 **GitHub 公共 REST API** 作为真实样板（沙箱可直连、免密钥、agent 高频调用）：

- `GET /zen` · `GET /rate_limit` · `GET /events`
- 经 MCPForge 全链路实测结果见 `examples/real_showcase_result.json`：

| 指标 | 结果 |
|---|---|
| Verify 真实 2xx | 3/3 全部通过（真实公网 200） |
| 真实调用计量 | 6 次真实 200 调用，成功率 100% |
| 计价档出账 | pro 档，每千次 $8，按真实用量折算 |
| 市场清单 | 3 个可调用工具，pay-per-call 模型，USD |

> 注：加密行情类 API（CoinGecko）在沙箱被出网策略拦截，故选 GitHub；
> 这反而更贴"agent 真正会调用"的评委口径。币种保持 USD，不碰代币投机红线。

## 五、评委叙事（3 分钟能讲完的故事）

1. **痛点**：所有人都在秀"我能把 spec 转成 MCP 工具"，没人回答"这个工具真能用、真能赚钱吗？"
2. **反转**：MCPForge 把官方四段式做成**一条真实闭环**——生成后真的去打 2xx，真的记用量，真的出账单。
3. **证据**：现场打开 `examples/real_showcase_result.json`，GitHub API 真实 3/3 通过、6 次真实计量、pro 档出账数字可核对。
4. **对齐变现**：Monetize 段输出 pay-per-call 就绪的工具，直接喂进 agent 经济（x402 / OKX.AI 结算对齐）——和官方主题最后一个词同构。
