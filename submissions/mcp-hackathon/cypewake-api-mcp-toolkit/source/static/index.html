MCP 端点 /mcp

工具策展（Tool Curation）

解决「100 个端点导出 100 个工具、撑爆 Agent 上下文」的问题。在生成前按 tag / 方法 / 路径 / 意图过滤。 留空则导出全部。
示例：{"intent":"user order","top_n":5} 按语义取最相关的 5 个操作； {"include_path_patterns":["/pet/*"],"exclude_methods":["DELETE"]} 只保留 /pet 下非删除操作。
默认使用公开免密钥的 Swagger Petstore。也可换成任意 OpenAPI/Swagger 的 URL、本地文件路径或直接粘贴文本。

BUILD解析与抽取

读 spec，展开 $ref、合并 path 级参数、识别鉴权方案与分页参数，产出带 JSON Schema 的操作清单。

VERIFY真实验证

并发真实调用端点，只把 HTTP 2xx 记为通过；401/403 记为需鉴权，4xx 记为参数错误，网络失败记为不可达。

MCPIZE生成可部署包

把整份 spec 生成为完整可部署的 MCP 服务包（server.py + 依赖 + 说明 + 清单），落盘即成品。

MONETIZE计量与出账

生成上架清单（含工具级 schema 与计费档位），并基于真实调用计量出账 —— 不是打印一张拍脑袋的价目表。

用量与账单

数据来自本服务每次调用时的真实计量（usage.json）。
