# MCPForge 市场调研 · 一页纸总结

**定位**：API→MCP 全链路工厂（Build→Verify→MCPize→Monetize），已在线部署、可真实调用。

## 行业（为什么是现在）
- MCP 已成为 AI Agent 连接生产 API 的"接线标准"（2024-11 提出，2026 年中确立）。
- 企业每接一个系统：传统 REST 2–8 周 → MCP 2–4 小时（提速 5–10×）。
- Gartner：2026 年底 75% API 网关将原生支持 MCP；每次集成周期可省 15 万美元+，维护降 70–80%。
- **结论：真实刚需、付费意愿强、窗口期就在 2026–2027。**

## 实用性（是什么）
把"已有 REST API"变成"Agent 可直接调用的 MCP 工具"，零胶水代码、先验证后交付、一体化流水线、可计量出账。生成物经实测可编译、可实例化为真实 FastMCP 服务。

## 对谁有帮助
| 人群 | 帮助 |
|---|---|
| Agent 开发者/小团队 | 几天接线 → 几分钟出可部署服务 |
| 企业平台/中台 | 复用工厂，一处更新全员受益，维护降 70–80% |
| API 产品/DevRel | 对外发布 Agent-Ready MCP 面，提升采纳 |
| 评审/运维/合规 | 真实调用证据 + 可审计计量 + SSRF 逐跳防护 |

## 竞争格局（必须诚实）
**红海，对手更强**：Speakeasy / Gram（托管+策展）、liblab、openapi-mcp-generator(~630★)、AWS Labs、FastMCP、Postman 等均已成熟。
**本作品差异点**：
- 四阶段可视化叙事、Verify 真实断言、计量出账、单进程即开即用+公网可验、SSRF 逐跳防护
- **v2.1 新增：内置工具策展层（scope filtering），把 100 端点收敛到 5 个 Agent 可用工具**，直接打到开源/轻量作品的最大短板

## 关键变化
🔴 **原最大短板「工具爆炸」已反转成差异点**：通过 `preview_scope` / `generate_mcp_bundle(scope)` / `verify_api(scope)` 等工具，MCPForge 现在能按 tag、方法、路径、意图做策展，并实时展示压缩率。

## 夺冠结论
实用性真实成立、对用户帮助可量化；工具策展把与 Gram/Speakeasy 的最大差距缩小为「托管 vs 工程化」的差距。当前仍是**强竞争者**，夺冠概率因策展功能而提升，但名次仍无法保证（评分权重未知）。最高杠杆下一步：**把 README/evidence 改写为评委视角（四段式 + 硬门槛 + 变现对齐），并完成 GitHub PR 提交（9/19 前，无需公网部署）**。
